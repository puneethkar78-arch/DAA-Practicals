### Summary

In this practical, I learned and implemented the Heap Sort algorithm. Heap Sort uses a binary heap data structure to arrange the elements and repeatedly extracts the largest element from the heap and places it at the end of the list. By building a Max Heap and maintaining the heap property during each step, I understood how Heap Sort efficiently sorts data. I also learned about its in-place sorting approach, working principle, and time and space complexity.

### Conclusion

From this practical, I concluded that Heap Sort is an efficient comparison-based sorting algorithm with a time complexity of **O(n log n)** in the best, average, and worst cases. It does not require additional arrays for sorting, making its space complexity **O(1)**. Overall, this practical improved my understanding of heap data structures, heapify operations, and how Heap Sort can be used to efficiently arrange elements.
